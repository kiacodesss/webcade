Intro to HTML

When it comes to creating any website or page on the web, you need the holy trinity: HTML, CSS, and Javascript! They are the backbone of every webpage you see on the internet, without it, you'll probably only see a plain white screen in every site you visit. Luckily, in websites like Spacehey, you don't have to to do any Javascript at all! Hooray! Moreover, this blog will focus solely on the basics of HTML and how you can structure your profile! I'll try to explain it as simple as I can.

What is HTML actually? HTML is short for HyperText Markup Language, it structures your webpage so that its clean and well-put together. Think of it as the builder like Felix from Wreck-it-Ralph!

As we go over the lessons, I will be sharing some code samples. To test the codes, you can use an online compiler like CodeChef to help you run the code easily.

HTML 101

In HTML, we use tags, attributes, and classes to keep things in place.

HTML Elements

HTML uses tags which we call "elements." An HTML element is everything from a start tag to the end tag. Tags in HTML are always enclosed by "< >" signs, and end tags always has a forward slash inside like:

<h2>This is an example</h2>

In the example above, <h2> is the start tag, while </h2> is the end tag. Now that you know what are the kinds of tags, these are the actual tags that you'll probably need in coding your profile:

  • <h1> - this defines the most important heading! It ranges from h1 (being the largest) and h6 (the smallest).
  • <p> - defines the paragraphs or body text.
  • <br> - insanely useful for making lists, this makes sure that it jumps to the next line.
  • <img src> - this helps you embed an image or gif on your page!
  • <center> - this will center the contents inside this tag.

Important: Always make sure that you use "< >" these signs when mentioning HTML tags.

HTML Attributes

HTML attributes provide additional information about our HTML elements. It's important to keep in mind that all HTML elements can have attributes and they are always specified in the start tag.

  • <src> - in the tag, the src specifies the actual source path like the source link so that it knows what image are you referring to.
  • <width> <height> - in the tag, you can absolutely use width and height attributes to specify an image's dimensions (in pixels).
  • <alt> - this shows an alternate text that will show if an image is unable to load correctly or when a user uses a screen reader.
  • <style> - this attribute is used to add styles to an HTML element (e.g., color, font, size, and etc.)

HTML Classes

Onto the more interesting part of HTML is the HTML classes. This is a genuine game changer because classes are the heart of HTML! To explain it better, just think of classes as containers. For example, you want to create a vinyl gallery of your favorite albums or songs, you need a class to put all the code for the vinyl gallery in a container so that it doesn't affect the outside elements.

When making a class, we use the <div> tag, followed by either a <class> or an <id>, then assign its value inside quotation marks like this:

<div class="elijah-woods">
<div id="elijah-woods">

  • <class> - you mostly use this when you want a container.
  • <id> - you use this when you want to apply a completely unique styling in you code for CSS.
